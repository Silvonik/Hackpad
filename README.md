# Hackpad
## About
I made a Hackpad that helps me with everyday repetitive keyboard shortcuts, so instead of needing to always Ctrl S to save I now only need to Press One key.

## Features
Ctrl C = copy
Ctrl V = paste
Ctrl X = cut
Ctrl S = save
Ctrl Z = undo
Ctrl Y = Redo
